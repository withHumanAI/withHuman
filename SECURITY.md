# Security policy

## Report a vulnerability

Report it privately through GitHub:
[open a private vulnerability report](https://github.com/withHumanAI/withHuman/security/advisories/new).
Only the maintainers can see it.

Don't open a public issue, pull request or discussion about a
vulnerability, and don't test against other people's data or
deployments.

Please include:

- the version or commit you tested,
- the steps to reproduce it,
- what an attacker could do with it, and
- any proof of concept you have.

Reports about the hosted edition at withhuman.ai are welcome here too,
since it runs this code.

## What happens next

We'll confirm we've received your report, keep you updated while we work
on a fix, and agree a disclosure date with you. Once the fix is released
we publish a security advisory, and credit you in it if you'd like.

## Supported versions

Fixes go into the next release. Run the latest release to stay protected.

## Running your own deployment

Securing a self-hosted deployment (HTTPS, trusted proxies, the secrets key,
backups) is up to its operator. The README's
[Deploy](README.md#deploy) checklist covers what to set.
