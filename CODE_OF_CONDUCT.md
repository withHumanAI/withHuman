# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies in every project space: issues, pull requests, discussions and
reviews.

## In short

- Be respectful and assume good intent.
- Give constructive, specific feedback about the work, never the person.
- Harassment, personal attacks, discriminatory language and sharing
  someone's private information are not acceptable.

## Report a problem

Report it privately to the maintainers through
[GitHub's private reporting form](https://github.com/withHumanAI/withHuman/security/advisories/new),
and say in the title that it's a code of conduct report. Only the
maintainers can see it, and we'll keep the reporter's identity
confidential.

## What we may do

Depending on what happened, we may edit or remove comments, lock a thread,
warn the person involved, or block them from the project.
